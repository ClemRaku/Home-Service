## 📖 Introduction

**Home Service** is a full-stack web application designed to streamline the process of booking and managing home maintenance services. Users can browse available services, view promotional offers, schedule appointments, and manage their accounts — while service providers and admins can efficiently handle bookings, manage employees, and track business operations.

The application features role-based access control (admin, employee, customer), appointment scheduling, promotional offer management, employee settings and experience tracking, and a responsive UI built with custom CSS.
