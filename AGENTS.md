# Agent Configuration

## MCP Servers

### Supabase MCP Server
Configured for this project. Use `supabase` tools when working with:
- Database queries and schema inspection
- Running migrations
- Accessing project logs and security advisors
- Managing edge functions
- Browsing Supabase documentation

**Config**: `opencode.json` (project-level)
**Auth**: Run `opencode mcp auth supabase` to authenticate on first use.

## Usage
Add to prompts: `use supabase to [action]`
